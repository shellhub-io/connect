##

ShellHub Desktop is an application designed to simplify and enhance the experience of connecting and managing
remote devices via ShellHub. With an intuitive and user-friendly interface, ShellHub Desktop allows users to
easily access their devices in **ShellHub Cloud** and on custom instances of ShellHub, whether it's
the **Enterprise Edition** or **Community Edition**, managed or self-hosted.

## Architecture

ShellHub Desktop is built with [Wails v3](https://v3.wails.io) (Go backend + Vue 3 / Vuetify
frontend rendered in the OS-native webview).

The active instance's web UI is embedded in an `<iframe>` served by a small Go **reverse proxy**
(`internal/proxy`) that strips iframe-blocking headers and proxies the SSH terminal websocket.
The embedded UI reaches native capabilities (e.g. local SSH keys) through a **postMessage bridge** —
see [`docs/native-bridge.md`](docs/native-bridge.md).

## Development

Requires Go 1.24+, Node 20+, and the Wails 3 CLI:

```bash
go install github.com/wailsapp/wails/v3/cmd/wails3@latest

# Linux build deps: libgtk-4-dev libwebkitgtk-6.0-dev

wails3 doctor          # verify the toolchain
wails3 dev             # run with hot reload
wails3 build           # build the binary into ./bin
wails3 task package    # produce a platform package
```

Go→TS bindings are generated into `frontend/bindings` (regenerated by `wails3 dev` / build, or
manually with `wails3 generate bindings ./...`).
